# 게임 실제 지도 이미지 (참고용, 미검증)

`game_world_map_step3_mosaic.png`: 사용자가 브라우저 개발자도구 네트워크 탭에서 실제 게임 타일(step3, qa-static.line.games) URL을 찾아 HTML로 일괄 로드 후 "웹페이지 전체 저장"으로 받은 타일들을 브라우저가 자동 배치한 전체 지도 이미지. 2026-09-15 확보.

**주의: 좌표 매칭 미검증 상태.**
- 라벨(도시명)이 하나도 없어서, 이 이미지의 픽셀 좌표와 기존 map_coordinates.json(step4 기준)의 좌표계가 어떻게 대응되는지 아직 확인 안 됨
- step3와 step4는 해상도가 다른 별개의 줌 레벨이라 단순 비례로 안 맞을 수 있음 (tileMap.sizes 참고: step3와 step4 픽셀 크기 재확인 필요)
- 사용 전 최소 3~4개 이상의 도시 위치를 이 이미지에서 직접 식별(또는 별도 라벨 있는 스크린샷과 대조)해서 로컬 변환식부터 다시 구해야 함
- 지금은 강 형태 육안 비교(정성적) 용도로만 신뢰 가능

# 해상 거리 계산용 육지/바다 마스크

## 개요
- `landmask.png`: 게임 지도(step4, 10000x5881px) 좌표계를 10px 격자로 나눈 육지/바다 마스크. 1000x588 픽셀, 흑백 PNG (흰색=육지, 검정=바다).
- Natural Earth 50m 해상도 육지 폴리곤(`ne_50m_land.geojson`, nvkelso/natural-earth-vector)을 아래 좌표 환산식으로 게임 좌표계에 매핑해 생성 (2026-09-15).

## 좌표 환산식 (data/map_coordinates.json의 coordTransform과 동일)
- 경도 -> 게임 x: `x = 27.79 * lon + 4697.2`
- 위도 -> 게임 y (메르카토르): `y = -1604.06 * ln(tan(pi/4 + lat_rad/2)) + 2947.3`
- 역변환: `lon = (x-4697.2)/27.79`, `m = (y-2947.3)/-1604.06`, `lat = degrees(2*atan(exp(m)) - pi/2)`

## 격자 규격
- CELL = 10 (게임좌표 10px = 마스크 1칸)
- 마스크 크기: 1000 col x 588 row (게임 지도 10000x5881px 커버)
- 마스크[row][col] == 1(흰색) → 육지(이동 불가), 0(검정) → 바다(이동 가능)

## 사용법 (A* 예시)
`astar_example.py` 참고. 두 도시/마을 좌표를 각각 가장 가까운 바다 칸으로 스냅한 뒤 8방향 A*로 최단 해상 경로를 구하고, 거리(px) = 노드 이동 비용 합 * CELL.

## 한계
- 폭이 매우 좁은 해협(파나마 등)은 원본 데이터 해상도(50m) 자체의 한계로 완전히 정확하지 않을 수 있음
- 게임이 실제 해안선을 100% 그대로 쓰지 않았을 가능성 있음(단순화, 강 표현 등) → 오차 감안 필요
- 스트라스부르/쾰른 좌표는 실측이 아닌 추정치라 이 지역 근방 경로는 다소 부정확할 수 있음

## 업데이트 (2026-09-15, 2차)
- 양쯔강(Yangtze) 하류~중류 구간을 항해 가능한 "바다"로 추가 반영 (Natural Earth `ne_10m_rivers_lake_centerlines.geojson`의 Yangtze 라인을 게임좌표로 변환 후 마스크에 반영, 중경까지 연결). 게임 자체가 일부 큰 강을 항해 가능하게 구현한 점을 반영.
  - 이 반영 후 마르세유-중경 거리가 6839px(강 없이 해안 직선 스냅, 부정확) -> 7536px(강 항로 경유, 더 정확)로 갱신됨.
- 코르프(캄차카 인근)의 북극 우회 항로는 테스트 결과 이 마스크(실제 지구 해안선 기반)로는 시베리아 북단이 막혀있어 연결되지 않음 -> 계산 불가. 게임이 실제로 이 항로를 열어뒀다면 게임 자체 좌표/지형 데이터가 필요함.

## 업데이트 (2026-09-15, 3차) - 사용자 제공 게임 스크린샷 기반 강 대량 반영
사용자가 직접 게임 내 지도 스크린샷을 지역별로 제공해서, 실제 게임에 구현된 항해 가능 강들을 확인하고 반영함.

**바다와 연결되어 유의미해진 강:**
- 나일강~콩고강: 누비아인의 마을 - 바리족의 마을 - 바간다족의 마을 - 후투족의 마을 - 벵겔라 - 루안다 (남대서양 연결), 북쪽으로 누비아인의 마을 - 카이로 (지중해 연결)도 별도 확인
- 잠베지강: 쇼나족의 마을 - 소팔라 (인도양 연결)
- 라인강: 앤트워프 - 쾰른(추정좌표) - 스트라스부르(추정좌표)
- 아마존강: 위토토족의 마을 - 히바로족의 마을 - 무라족의 마을 - 투카노족의 마을 - 카옌 (대서양 연결)
- 파라나강(리오데라플라타): 시리오노족의 마을 - 보로로족의 마을 - 과라니족의 마을 - 부에노스아이레스 (대서양 연결). 이 강 덕분에 이 세 마을이 "남서부아메리카" 지역으로 분류되는 것이 지리적으로 확인됨.

**바다와 연결되지 않는(내륙 전용) 강 - 확인했지만 반영은 각 마을간 연결만 의미있음:**
- 니제르강: 팀북투 - 말링케족의 마을 - 요루바족의 마을 - 반투족의 마을 (스크린샷상 바다로 이어지지 않고 반투족의 마을에서 끝남)
- 티그리스강: 바그다드 - 루르인의 마을
- 북미 내륙 강: 수족의 마을 - 포니족의 마을 - 샤이엔족의 마을

**북극항로 정정:** 이전 버전에서 "북극항로 전체가 막혀있다"고 판단했던 것은 오류. 나르비크~바르도~아르한겔스크~네네츠인의 마을 구간은 원래부터 정상적으로 연결되어 있었음. 실제 병목은 타이미르 반도(첼류스킨 곶) 부근으로, 이 구간을 사용자 스크린샷 확인 후 연안을 따라 우회하는 형태로 수동 연결함. 이후 마르세유-코르프 거리가 8831px(희망봉 경유) -> 7532px(북극항로)로 단축되어 북극항로가 실제로 더 짧은 것으로 확인됨.

## 업데이트 (2026-09-15, 8차) - 실제 게임 이미지 기반으로 마스크 전면 교체
사용자가 실제 게임 타일(step4, qa-static.line.games)을 HTML+"웹페이지 전체 저장" 방식으로 확보해서 제공. 이 실제 지도 이미지(2995x1768, step4 좌표계와 동일 비율)의 색상(바다=RGB[90,111,102] 기준 색상거리)으로 육지/바다를 직접 분류.

**효과:**
- 기존 Natural Earth + 메르카토르 역산 방식은 고위도에서 왜곡이 심해 북극항로 등에서 부정확했음(사용자가 오버레이 비교로 확인) -> 실제 게임 이미지 기반으로 전면 교체하여 근본 해결.
- 강도 대부분 자동으로 마스크에 포함됨(강물 색상이 바다색과 유사해서 자동 검출) - 니제르강, 나일강, 아마존강, 양쯔강 등이 손으로 안 그려도 이미 마스크에 나타남.
- 북극항로(북동/북서 모두) 이제 인위적인 우회선 없이 실제 데이터로 자동 연결됨.
- 다만 0.3배 축소본이라 일부 가는 강(중경/양쯔강 일부 구간, 야쿠트인의 마을 강)은 축소 과정에서 유실되어 재차 수동으로 이어붙임.

**한계:**
- 사용된 이미지가 실제 step4(10000x5881) 전체를 0.3배로 축소한 버전이라, 세부 해상도는 여전히 제한적(약 3.3게임px당 1마스크px). 더 정밀한 마스크가 필요하면 축소 없는 원본 타일 전체를 이어붙여야 함.
- 쾰른/스트라스부르 좌표는 이번 업데이트로 검증되지 않음(별도 확인 필요).

## 업데이트 (2026-09-15, 11차) - 다운샘플링 제거, 원본 해상도로 재구축
직전 버전이 원본 이미지(1906x1125)를 1000x588로 축소해서 만드는 바람에 불필요하게 해상도를 낮췄던 문제 수정.
- 이제 마스크가 원본 이미지 해상도(1906x1125) 그대로 사용됨. CELL 개념 대신 SX=10000/1906≈5.2466, SY=5881/1125≈5.2276 (게임px per 마스크 픽셀)로 좌표 변환.
- 강/항로 전부 재적용 및 재검증 완료 (야쿠트인의 마을 연결 브릿지 1건만 재보정 필요했음).
- A* 등 경로탐색 코드도 이 새 SX/SY 스케일 기준으로 다시 맞춰야 함 (기존 CELL=10 가정 코드는 이 마스크에 안 맞음).

# 해상 거리 계산용 육지/바다 마스크

## 개요
- `landmask.png`: 게임 지도(step4, 10000x5881px) 좌표계를 10px 격자로 나눈 육지/바다 마스크. 1000x588 픽셀, 흑백 PNG (흰색=육지, 검정=바다).
- Natural Earth 50m 해상도 육지 폴리곤(`ne_50m_land.geojson`, nvkelso/natural-earth-vector)을 아래 좌표 환산식으로 게임 좌표계에 매핑해 생성 (2026-09-15).

## 좌표 환산식 (data/map_coordinates.json의 coordTransform과 동일)
- 경도 -> 게임 x: `x = 27.79 * lon + 4697.2`
- 위도 -> 게임 y (메르카토르): `y = -1604.06 * ln(tan(pi/4 + lat_rad/2)) + 2947.3`
- 역변환: `lon = (x-4697.2)/27.79`, `m = (y-2947.3)/-1604.06`, `lat = degrees(2*atan(exp(m)) - pi/2)`

## 격자 규격
- CELL = 10 (게임좌표 10px = 마스크 1칸)
- 마스크 크기: 1000 col x 588 row (게임 지도 10000x5881px 커버)
- 마스크[row][col] == 1(흰색) → 육지(이동 불가), 0(검정) → 바다(이동 가능)

## 사용법 (A* 예시)
`astar_example.py` 참고. 두 도시/마을 좌표를 각각 가장 가까운 바다 칸으로 스냅한 뒤 8방향 A*로 최단 해상 경로를 구하고, 거리(px) = 노드 이동 비용 합 * CELL.

## 한계
- 폭이 매우 좁은 해협(파나마 등)은 원본 데이터 해상도(50m) 자체의 한계로 완전히 정확하지 않을 수 있음
- 게임이 실제 해안선을 100% 그대로 쓰지 않았을 가능성 있음(단순화, 강 표현 등) → 오차 감안 필요
- 스트라스부르/쾰른 좌표는 실측이 아닌 추정치라 이 지역 근방 경로는 다소 부정확할 수 있음
